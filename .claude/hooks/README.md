# hooks/

Scripts referenced by absolute path from `~/.claude/settings.json` hook configuration: compaction
resilience, ruff autofixing, changed-lines linting, web-search rate limiting, new-dependency flagging,
changelog-before-commit ordering, and Excalidraw binding validation. See
[`../../docs/01-hooks.md`](../../docs/01-hooks.md) for what each one does and how to test it standalone.
